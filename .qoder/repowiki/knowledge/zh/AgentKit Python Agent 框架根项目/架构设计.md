根目录仅承载项目元数据（pyproject.toml、uv.lock、.env.example）与 README；所有源码集中在 src/agentkit 包内，按职责单向分层：core 提供零依赖的消息模型/事件/错误/配置，llm、tools、observability 仅依赖 core，runtime 聚合全部子模块实现引擎循环、事件总线、预算、取消与审批，app 仅依赖 runtime 暴露 agentkit CLI 与 FastAPI SSE 服务。tests 通过 conftest.py 中的 ScriptedModel 把 LLM 不确定性收敛到边界，使引擎、工具、流式输出等逻辑完全确定性；integrations 作为可选适配层在运行时之上提供 LangChain 双向互操作。依赖方向由 README 明确约束（tools 不 import runtime，审批接口由 runtime 注入）。
