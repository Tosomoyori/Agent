- 内部消息统一使用内容块模型（TextBlock / ToolUseBlock / ToolResultBlock），而非 OpenAI 原生 tool_calls 结构，以便直接映射 Anthropic 协议。
- 引擎对外只 yield 类型化事件，SSE、CLI、可观测与评测共享同一条流，避免返回值与回调双真相源。
- 工具参数经 pydantic 校验，失败时回灌为可读错误结果让模型自我修正，而不是抛出异常中断 run。
- 路径安全用 realpath + commonpath 解析符号链接后再比较前缀，命令执行采用拒绝/放行/转审批三分裁决而非黑名单。
- 测试通过 ScriptedModel 固定 LLM 输出，所有非 live 用例不碰网络、不花钱、结果可复现。
