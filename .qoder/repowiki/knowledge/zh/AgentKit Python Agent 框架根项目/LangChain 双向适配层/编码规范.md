- LangChain 相关 import（如 `convert_to_openai_tool`、`asyncio.to_thread`、`concurrent.futures.ThreadPoolExecutor`）延迟到函数体内部，保证核心包在无 langchain 时可导入。
- 思维链内容统一写入 `additional_kwargs[_REASONING_KEY]`（键名 `reasoning_content`），并在反向读取时还原为 `ReasoningBlock`，避免 DeepSeek 多轮工具调用返回 400。
- 工具往返转换时通过显式 `workspace` 参数固定上下文根目录，避免 `Path.cwd()` 在调用方上下文中漂移。
- 从第三方生态引入的工具默认保守标记：`dangerous=False`、`idempotent=False`，需要审批语义时由调用方显式开启。
- 同步入口 `_generate` 通过检测 `asyncio.get_running_loop()` 区分「无事件循环」和「已有事件循环」两种情况，分别用 `asyncio.run` 或 `ThreadPoolExecutor` 调度异步实现。
