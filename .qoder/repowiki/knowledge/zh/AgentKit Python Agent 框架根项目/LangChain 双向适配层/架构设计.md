模块由 `src/agentkit/integrations/langchain.py` 单一文件构成，按职责划分为三块：
- 消息转换：`to_langchain_messages` / `from_langchain_messages` 在 AgentKit 的 `Message`（含 `ReasoningBlock`、`ToolUseBlock`、`ToolResultBlock`）与 LangChain 的 `AIMessage`/`HumanMessage`/`SystemMessage`/`ToolMessage` 之间做双向映射；`_as_text` 统一处理字符串或 content block 列表。
- 模型适配：`AgentKitChatModel(BaseChatModel)` 通过覆写 `_generate`/`_agenerate`/`_astream` 把 LangChain 调用转到底层 `ChatModel.complete/stream`，并实现 `bind_tools` 以支持 LCEL 管道和 agent；`_schemas_from_kwargs` 从 `bind_tools` 传入参数中提取 OpenAI 格式的工具 schema。
- 工具适配：`to_langchain_tools` 把 `ToolRegistry` 转为 `StructuredTool` 列表（剥离注入的 `ToolContext`，固定 `workspace`），`from_langchain_tools` 反向构造 `ToolRegistry`，默认标记 `dangerous=False`、`idempotent=False` 以保守对待第三方工具。
依赖方向单向指向 `agentkit.core`、`agentkit.llm.base`、`agentkit.tools`，不触碰 `runtime`；示例 `examples/langchain_interop.py` 演示四向用法：AgentKit 模型作为 LangChain 模型、进入 LCEL 管道、消息双向转换、以及把 LangChain 工具接回 AgentKit 注册表。
