测试按被测子系统拆分为独立文件：`test_engine.py`（引擎事件循环）、`test_runtime.py`（Agent 生命周期）、`test_streaming.py`（增量拼接）、`test_tools.py`（工具注册/执行）、`test_retry.py`（错误回灌与重试）、`test_policy.py`、`test_memory.py`、`test_openai_compat.py`、`test_types.py`。

核心设计集中在 `conftest.py`：
- `ScriptedModel(ChatModel)` 是统一假模型，仅实现 `stream()`，通过预设脚本（完整 Message / 预切 StreamChunk 序列 / Exception）驱动所有断言，把网络、费用、不确定性收敛到 LLM 边界；
- 辅助构造器 `assistant_text`、`assistant_tools`、`text_chunks` 生成确定性输入；
- `workspace`、`ctx`、`registry` 等 fixture 提供隔离的文件系统与空工具注册表。

`test_live.py` 使用 `pytest.mark.live` 标记，默认被 `-m 'not live'` 排除，仅在显式 `uv run pytest -m live` 时运行真实 LLM 调用，断言宽松以验证协议连通性而非答案正确性。依赖方向单向：测试 → agentkit 源码，不反向依赖。
